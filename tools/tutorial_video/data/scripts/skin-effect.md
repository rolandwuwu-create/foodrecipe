# 高頻世界裡，粗電線的心是空的。｜集膚效應

系列：小東老師電子學
片長目標：約 4–5 分鐘成片（旁白決定每鏡長度）
金句：高頻世界裡，粗電線的心是空的。

## 旁白全稿（可直接配音）

線已經換很粗了，算電阻也覺得夠低，結果一上高頻還是燙得像剛出爐。高頻世界裡，粗電線的心是空的。

這不是線材買太便宜。你用三用電表量直流電阻，數字漂亮得很。可是開關電源一上、變壓器一繞，甚至音響分音器一過高頻，線就開始燙。

低頻的時候，電流幾乎把整根銅都當路用。截面積你買多少，路就有多寬。

高頻一來，交變電流自己會生磁場，這個磁場在導體裡面感應出渦電流。結果電流被趕到表皮。頻率越高，那層皮越薄。這就是集膚效應。

你付錢買的是整根截面積。高頻時真正在載流的，只剩外面那圈。中間那塊實心銅，常常在旁邊看戲。

看起來像實心棒，高頻時比較像一根管子。管子有電流，裡子很空虛。

所以交流電阻會比直流電阻高。熱是電流的平方乘上電阻，電阻變大，同樣的電流就更燙。再粗一號，低頻有用；高頻時你只是買了更厚的、不走路的心。

現場怎麼辦？不是無腦換更粗。多股絞線、利茲線，是在把皮變多，讓每一股都有表皮可以走路。

PCB 則常走寬而薄的銅箔，讓電流有表皮可以躺。很高頻才輪到鍍銀、空心銅管。先問頻率，再決定要不要把心掏空。

記住這句：高頻世界裡，粗電線的心是空的。管子有電流，裡子很空虛。

我是小東老師。這集是集膚效應。下一題，我們講鄰居那根線，怎麼繼續偷你的電流。
