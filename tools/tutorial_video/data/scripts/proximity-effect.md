# 旁邊那根線，也在偷你的電流。｜鄰近效應

系列：小東老師電子學
片長目標：約 4–5 分鐘成片（旁白決定每鏡長度）
金句：旁邊那根線，也在偷你的電流。

## 旁白全稿（可直接配音）

集膚懂了，線也換粗了。兩根一平行，一上高頻，還是燙。旁邊那根線，也在偷你的電流。

這題很常發生在開關電源、變壓器繞組，還有 PCB 上兩條並排走很長的銅箔。你用電表量直流電阻，數字漂亮得很，交流一上卻開始發燙。

先把集膚講清楚。低頻的時候，電流幾乎把整根銅都當路用。高頻一來，電流被自己的磁場趕到表皮。

所以你付錢買的是整根截面積，高頻時真正在載流的只剩那層皮。可是把線換粗，甚至換成管子，兩根還是平行長走，問題不會消失。

因為鄰居也有磁場。一根線的磁場，會去推旁邊那根線裡的電流。這就叫鄰近效應。

兩根電流同方向時，電流會被擠到外側；反方向時，電流會被擠到面對面那一層。差動對、緊密繞組，最常看到的就是面對面那層在載流。

兩根平行長走時，電流擠在面對面那一層，外側幾乎在看戲。等於有效截面積又被偷走一次。它不是把線變細，是把能走路的銅再偷走一回。

變壓器、電感繞組把線匝一圈貼一圈，是鄰近效應的重災區。你以為用粗線就能扛電流，結果交流電阻被匝間磁場抬上去，核心先熱、線包也熱。

直流電阻沒變。變的是交流電阻。集膚加鄰近，交流電阻往上跳。熱是電流的平方乘上電阻，電阻變大就更燙。線徑再粗，也救不了兩根貼太近。

所以現場不是再粗一號。線徑解決不了鄰居。先做三件事。

第一，拉開間距。鄰居遠一點，磁場就沒那麼兇。能分開就不要貼著走。

第二，少做平行長走。不得不平行，就縮短耦合的長度。PCB 並排差動可以近，那是有意耦合；電源大電流的回流，就不要跟它平行貼著走二十公分。

第三，高頻繞組才輪到利茲線、交錯繞、三明治繞。那是把皮變多，也把鄰居錯開。順序很重要：先問佈局，再換線材。

記住這句：旁邊那根線，也在偷你的電流。集膚是自己偷自己，鄰近是鄰居來偷你。線徑解決不了鄰居。

我是小東老師。這集是鄰近效應。下一題，我們繼續把高頻裡那些以為懂了還是燙的題目拆開。
